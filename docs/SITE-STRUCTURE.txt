八、关键容器对照（虚幻引擎 → CSS）
================================================================================

  Vertical Box              display: flex; flex-direction: column
  Horizontal Box            display: flex; flex-direction: row
  Slot: Fill（按比例分）     flex: <n> 1 0
  Slot: Auto（按内容）       flex: 0 0 auto
  Size Box（最小尺寸）       min-width / min-height
  Spacer                    gap / 空的 flex 子项
  Padding                   padding / margin
  Scale Box / DPI Scaling   clamp() + vh
  Anchors                   position + inset，或者干脆用 flex 分栏
  Overlay（叠放）            position: relative + absolute
  Widget Switcher（互斥切换） display: none / flex + 状态类名

九、改布局前的检查清单
================================================================================

  1. 先确认要改的元素「父级是谁」—— 打 el.parentElement.className，
     不要按肉眼层级猜。.home-top、#pmPlain 这两层就是这么被漏掉的。

  2. 用 flex: 1 之前，确认从根到它的每一层都是「有高度的 flex 容器」。
     少一层，flex: 1 就是 0。

  3. 元素量出来 0×0 时，先查祖先的 display / overflow，
     别在样式优先级上打转（!important、内联样式都试过才发现祖先被 display:none）。

  4. 只改一端时，CSS 只动对应的那个文件。skin-c.css 管桌面，
     mobile.css 管手机，别在一端里写 @media 去影响另一端。

  5. 加暗色配色时，注意 background: linear-gradient(...) 这类写法 ——
     只写 background-color 盖不住渐变，得同时 background-image: none。

  6. 改完必须跑：桌面 1920×919 + 手机 500×900，五个页面看错误和横向溢出。
