为什么看不到 CPU 型号和硬盘容量？

浏览器出于防追踪的考虑，故意不把这些信息开放给网页 —— 任何网站都读不到你的 CPU 具体型号、 硬盘多大、主板是什么。左边这些已经是网页能拿到的全部了，而且只在你本机读取，不会上传。

想看完整配置，用系统自带的工具就够，不用装任何软件：

  • Windows：按 Win + R，输 dxdiag 看显卡和 CPU，输 msinfo32 看全部
  • macOS：左上角苹果标 →「关于本机」→ 更多信息 →「系统报告」
  • Linux：终端里 lscpu（CPU）、lspci | grep -i vga（显卡）、free -h（内存）

还没有填网址

填一个网址，生成一个小文件。把它拖到桌面，以后双击就直接打开这个网站 —— 不用先开浏览器、再去翻收藏夹。

哪些系统能用
系统能不能用
Windows两种都行
macOS只能用 .html
Linux只能用 .html
手机 / 平板用不了

手机为什么不行：这套靠的是桌面系统「双击文件 → 交给默认程序打开」的机制。 手机上的文件点击后由 App 接管，iOS 和 Android 都不允许一个文件直接唤起浏览器打开网址， 所以做不出来。手机请用浏览器菜单里的「添加到主屏幕」 —— 那才是手机上的正确做法，效果还更好。

macOS / Linux 为什么只能用 .html：.url 是 Windows 专有的 「Internet 快捷方式」格式（本质是个 INI 配置），这两个系统不认，双击没有任何反应。 .html 是通用的，任何桌面系统都能用。

下载时浏览器可能提示风险：Windows 下存 .url 时，浏览器可能提示 「此类文件可能有害」。这是对所有快捷方式类文件的通用提示，选「保留」即可。 文件是纯文本，记事本能打开核对，不含追踪、也不会联网。
